## Selected projects

### [Plumbline — SaaS Security Posture Scanner](https://github.com/Rahul03082001/plumbline-sspm)

A read-only Go scanner that evaluates 9 YAML security rules across GitHub organizations, users, repositories, and webhooks. It handles pagination, rate limits, and retries, and keeps unreadable findings **unverifiable** instead of incorrectly marking them resolved.

**Go · GitHub REST API · SQLite · Docker · 75 Go tests + 2 Playwright tests**

[Code](https://github.com/Rahul03082001/plumbline-sspm) · [Live demo](https://demo-repository-ptyr.onrender.com/) — the free demo may take about a minute to wake.

### [SASEGuard — Zero Trust Access & Data Protection Lab](https://github.com/Rahul03082001/SASEGuard)

A four-service security lab with RS256 authentication, role-based access, device posture checks, text-based DLP, and redacted audit logs. Requests fail closed when policy checks or required audit writes fail.

**Python · FastAPI · SQLite · Docker Compose · 185 tests**

[Code and setup](https://github.com/Rahul03082001/SASEGuard) · [Live demo](https://saseguard.duckdns.org/) — demo credentials are deployment-specific; local setup is documented in the repository.

### [RankForge — Hybrid Search & Learning to Rank](https://github.com/Rahul03082001/rankforge)

A search application over 57,638 FiQA documents, combining keyword and semantic retrieval with reciprocal rank fusion and an XGBoost reranker. It includes reproducible evaluation and a UI for comparing rankings and inspecting source documents.

**Python · FastAPI · React · TypeScript · FAISS · XGBoost**

[Code and evaluation](https://github.com/Rahul03082001/rankforge) · [Live demo](https://rankforge-hg5yrz427q-ue.a.run.app/)
